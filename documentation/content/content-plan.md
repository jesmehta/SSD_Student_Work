# Content plan

The six galleries currently planned for SSD Student Work:

## Creative Coding

Interactive galleries of student p5.js sketches, one folder per student.

- Creative Coding - SSD 2024-25 — not yet started.
- Creative Coding - SSD 2025-26 — exists (14 students), moved here from the
  old single-purpose repo root.

## Emergent Technologies

Student project/outcome galleries: images, video, interactive projects,
descriptions, attribution. May eventually reuse the Creative Coding
interaction model — not decided, no material to design against yet.

- Emergent Technologies - SSD 2024-25 — not yet started.
- Emergent Technologies - SSD 2026-27 — not yet started.

## Papier-mâché

Simpler, image-led galleries; no interactivity expected.

- Dragons of SSD - A Papier-mâché Menagerie — not yet started.
- Playing with Pulp - Best of Papier-mâché at SSD — curated selection across
  papier-mâché work; not yet started, and by nature depends on Dragons of
  SSD (or other papier-mâché work) existing first to curate from.
