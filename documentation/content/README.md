# Content documentation

This folder is for **content, curation, and planning** — what goes in each
gallery, what material exists or is still needed, naming/selection
decisions, student attribution requirements. It is deliberately separate
from `documentation/` (repo/site *technical* documentation: structure,
deployment, routing).

Keep the two apart: a decision about which student projects belong in a
gallery is a content decision and belongs here; a decision about how a
gallery's HTML/CSS/JS is structured is a technical decision and belongs in
the parent `documentation/`.

- [gallery-status.md](gallery-status.md) — content readiness per planned gallery.
- [content-plan.md](content-plan.md) — the six planned galleries and their intent.
- [content-decisions.md](content-decisions.md) — naming/selection/curation decisions as they're made.
- `notes/` — free-form working notes, created as needed.
