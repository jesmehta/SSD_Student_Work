# Documentation

Technical/site documentation for the SSD Student Work repository — how the
repo and site work, not what goes in each gallery.

- [architecture.md](architecture.md) — repo structure, gallery model, why
  each gallery is unusual rather than one universal framework.
- [deployment.md](deployment.md) — GitHub Pages, the Cabinet multi-repo
  assembly that mounts this repo into `teaching/`, and current URL
  implications.
- [changelog.md](changelog.md) — dated log of structural changes.

Content, curation, and gallery-planning notes live separately under
[content/](content/) — see [content/README.md](content/README.md) for why
that split exists.
