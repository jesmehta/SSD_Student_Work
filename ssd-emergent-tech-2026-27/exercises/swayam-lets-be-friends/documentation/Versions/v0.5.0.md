# v0.5.0 — Replica Movement Behaviour

## Description

v0.5.0 introduces the first working version of the **Evil Replica's movement behaviour**.

The replica is no longer a completely stationary development rectangle.

It now responds to the player's detected facial and head movement through the face-tracking system developed in v0.4.0.

The replica is intentionally designed to respond in the **opposite direction** to the player's movement.

This creates the first visual separation between the player and the replica.

---

# Starting Point

At the beginning of this development stage, the application already had:

- Camera access.
- Mirrored webcam display.
- MediaPipe Face Landmarker.
- 478 facial landmarks.
- Face detection.
- Face position detection.
- Head movement detection.
- Smile detection.
- Development landmark visualization.

v0.5.0 uses this existing information to control the replica.

---

# Replica System

A dedicated replica element was added to the camera stage.

The current development replica is represented by a simple rectangle.

Its purpose is to make the movement system easy to observe during development.

The current replica is not the final visual appearance of the Evil Replica.
