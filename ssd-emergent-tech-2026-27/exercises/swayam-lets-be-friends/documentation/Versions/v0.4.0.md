# v0.4.0 — Face Tracking

**Date:** 21 August 2026

**Status:** In Development

---

# Overview

v0.4.0 begins the transition from a simple webcam interaction into a system that can understand the player's face.

The main purpose of this version is to introduce real-time facial tracking.

The first completed step is basic face detection.

The project can now determine whether a face is visible in the webcam feed.

---

# Goal

The long-term goal of v0.4.0 is to replace the simulated camera interactions from v0.3.0 with real camera-based understanding.

The intended progression is:

**Face detected**

↓

**Face position**

↓

**Head movement**

↓

**Facial landmarks**

↓

**Expression detection**

↓

**Smile detection**

↓

**Replica interaction**

The horror will NOT be introduced during this stage.

---

# Step 1 — Basic Face Detection

## Status

**Completed**

The first face-tracking implementation is working successfully.

# Technology

The project uses:

**MediaPipe Face Landmarker**

The Face Landmarker runs in the browser and processes the live webcam video.

The project also contains the trained model locally.
