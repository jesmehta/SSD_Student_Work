# v0.1.0 — First Conversation

**Date:** 21 August 2026

**Status:** Working Prototype

---

## Overview

v0.1.0 is the first working version of Evil Replica.

This version establishes the basic conversational experience between the player and the digital character.

The experience intentionally remains completely friendly and contains no horror elements.

The purpose of this version is to establish the character, conversational tone, interaction flow, and emotional foundation before introducing the webcam.

---

## Added

### Interface

- Minimal white interface
- Clean typography
- Centered dialogue
- Simple interaction buttons
- Name input field

### Dialogue System

- Opening conversation
- Character typing effect
- Player name interaction
- Branching dialogue
- Multiple character responses
- Friendship conversation
- Camera invitation setup

### Character Development

The character is designed to initially feel:

- Curious
- Friendly
- Playful
- Slightly lonely
- Interested in the player

### Player Interaction

The player can:

- Enter their name
- Respond to questions
- Choose different conversation responses
- Accept or delay friendship
- Accept or delay the character's request to ask a question
