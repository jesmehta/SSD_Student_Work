# Emergent Technology 2026–27

GitHub Pages-ready exhibition site for interactive student submissions.

## Status

The exhibition shell and provisional catalogue are present. Student exercises have not yet been copied or converted. Each exercise will be processed as a separately approved batch.

## Local preview

Serve this directory through a local HTTP server. Camera-based exercises will require HTTPS when deployed; GitHub Pages provides HTTPS.

## Publishing

Publish this directory as the root of a GitHub Pages site, or copy its contents to the root of the publishing repository. All internal paths must remain relative so the site works at both user and project Pages URLs.

Custom Teachable Machine models and their version-pinned JavaScript runtimes are archived locally in this project. Camera access still requires a secure context such as GitHub Pages HTTPS.
